# Клёв

Текстовая рыбалка в Telegram. Забрасываешь удочку, ждёшь поклёвку и подсекаешь, пока рыба не ушла.

Игра своя: локации, удочки, наживка, садок, справочник, достижения и топ. По духу это тот же формат, что у [@EndlessFishingBot](https://t.me/EndlessFishingBot) — короткая рыбалка прямо в чате.

## Как играть

1. Нажми **Рыбачить** и дождись кнопки **Подсечь**.
2. Чем быстрее подсечка, тем тяжелее рыба. Если опоздать — улов уходит.
3. Рыба копится в садке. Продай её и купи удочку получше.
4. Наживка повышает удачу и тратится на каждую поклёвку.
5. Новые водоёмы открываются с уровнем. Дальше вода — крупнее добыча.

В начале на счету 50 монет. В садок влезает 40 рыб.

## Общий чат

1. Создай группу в Telegram и добавь туда бота.
2. В группе напиши `/here`. Этот чат станет общим водоёмом: забросы видны всем, садок у каждого свой.
3. В личке у бота появится ссылка на чат. Её можно кидать друзьям.

Если ссылка не появилась, сделай группу публичной или назначь бота админом с правом приглашать и снова напиши `/here`.

## Запуск

Бот стартует сам при входе в Windows: файл `start_klev.vbs` лежит в автозагрузке. Компьютер должен быть включён, и ты должен быть залогинен. Если ПК выключен, бот тоже спит.

Лог пишется в `bot.log`. Остановить автозапуск: удали `start_klev.vbs` из папки автозагрузки и закрой скрытый процесс `python.exe bot.py` в диспетчере задач.

Ручной запуск, если задачи нет:

Нужен Python 3.10+ и токен от [@BotFather](https://t.me/BotFather): команда `/newbot`, затем скопируй выданный токен.

```cmd
cd /d "c:\Users\Roma\Desktop\Fish bot"
py -3 -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt
copy .env.example .env
notepad .env
.venv\Scripts\python bot.py
```

В `.env` одна строка:

```env
BOT_TOKEN=123456:ABC...
```

При ручном запуске окно не закрывай. Если работает задача `KlevFishingBot`, отдельное окно не нужно. Прогресс игроков лежит в `fishing.db`.
